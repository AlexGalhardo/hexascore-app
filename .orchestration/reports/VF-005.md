# VF-005: keyset pagination over a composite order

- Status: merged in vukem main (PR #11, squash afbce68), unreleased.
- Branch: feat/vf-005-keyset-orderby.
- API: `Query.CursorPaginate` now honours `OrderBy`/`Latest`: keyset = order columns + primary key (in `dir`) as tie-breaker; predicate `(k1 op v1) OR (k1 = v1 AND k2 op v2) ...` (mixed directions, all dialects). Cursor values decode into the columns' Go types (`time.Time`, `int64` exact); pk-only cursors keep the old format; bad arity/type -> 400 `ErrInvalidCursor`.
- Not signed on purpose (documented): values are bound parameters and columns come from validated `OrderBy`; a forged cursor only moves the start row. The app's own signing can be dropped.
- Tests: `TestCursorPaginateOrderBy`, extended `TestCursorPaginateErrors`, `FuzzDecodeCursor` (fuzz.yml).
