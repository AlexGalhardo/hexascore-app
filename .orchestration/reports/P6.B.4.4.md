design: rollback is a chain (rollback, normalize, dq.asserts) started by `ingest.StartRollback` after `rollback.Check` (fetch.* or tmdb.expire, finished, created less than 30 days ago, not rolled back yet). The step restores the pre-run history version of each record the run changed (normalized_at cleared, the history rows used are deleted) and deletes records the run inserted. Items created after the run started are deleted unless a rating, status, time-to-beat, list or user edition references them (then visibility = hidden). Each removed or hidden item gets a catalog_audit row (source admin, field `*ingest-rollback*`) and a search_dirty entry. The rollback is a job_runs row (mode rollback, params target_run/actor/reason, triggered_by admin:<id>). `POST /admin/ingest/runs/{id}/rollback` (ability rollbackIngestion, admin only): 303; 404 unknown run; 409 history-expired, already rolled back, run-active; 422 no reason or not a fetch run. `run.Prune`: history 30 d, dq_results and field_coverage 365 d, job_runs 180 d. `run.RetryFailures`: per source, up to 500 non-parked targets sent as the `qids` param (needs FIX-ingest-qids-param), skipping sources whose kill switch is off; normalise failures go back to the pending index and a normalize run is queued. Schedules: `ingest:prune` 02:30 and `ingest:retry-failures` 03:30 (Sao Paulo).
deviations: prune and retry are scheduler funcs, not queue jobs (no chunking needed). job_runs older than 180 d that still have dq_results or field_coverage (kept 365 d, FK without cascade) stay until those age out; no migration. No Playwright spec.
risks / follow-ups: a record a later run changed again is skipped (counted); an inserted record a later run touched is not deleted; records deleted by tmdb.expire cannot be restored (deletes leave no history); deleted items emit no api_changes row or ItemsChanged event (search is resynced, API webhooks are not); editions and backfill.editions failures are not retried. Check the catalog_audit use (free-text field, no enum change).
changelog: Added (rollback of a bad ingestion run, retry of failed ingestion targets, ingestion retention prunes).
