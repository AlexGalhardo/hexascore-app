It counts 200 GETs of /{section}/{slug} (locale prefix stripped) and /app/v1/{section}/{id}; Key = (item type, slug-or-id, UTC day). The flush resolves the ref against public items in SQL, so no lookup per view and no controller change; unknown or non-public refs insert nothing.
- Dedup: cache.Add on cache.NewMemory(300_000), key HMAC-SHA256(daily_salt, visitor|item), TTL to 00:00 UTC. Salt = app.DeriveKey("trending.views."+day). Visitor = bearer token hash (/app/v1), else session cookie, else IP via ratelimit.ByIP (IPv6 prefix). 50 distinct items per visitor per day. - Counter: bounded (100k keys) insertion-ordered map; failed flush merges back at the old end; drops counted by otel counter trending.counter.dropped.
- Flush: s.Func("trending:flush").EveryMinute() and app.OnShutdown, one transaction.
- SearchResultClicked: bootstrap/recommend_provider.go listens to search.ResultClicked, uses only ItemID.
