decisions:
- Test count = max(2, ceil(20 %)); a user with fewer than 3 ratings is skipped (nothing to train on).
- Precision divides by k even for a short list; nDCG is binary, 0 without positives.
- Bootstrap: percentile interval, seeded PCG (math/rand/v2 with nolint for depguard and gosec: reproducibility, not security).
- Coverage = distinct recommended items / catalogue size.
- CSV via encoding/csv with a leading-apostrophe guard on = + - @ tab CR (VF-029 workaround, no response helpers).
- Job `recommend.eval_monthly`, MonthlyOn(1, "05:30"), writes RECO_EVAL_DIR/reco-eval-YYYY-MM.csv through os.Root when the variable is set, else logs only. When triggered it only records the fact; the hold-out comparison of both recommenders is run by hand with eval.Evaluate (no harness that rebuilds a recommender from train-only data is in this row).
risks: RECO_EVAL_DIR is a new optional env var (not in .env.example, undocumented elsewhere). "Counted ratings" is taken as rows in ratings (no burst filter). Content baseline at launch + 90 days stays an owner calendar item.
