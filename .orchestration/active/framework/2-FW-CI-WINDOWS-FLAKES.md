# Task FW-CI-WINDOWS-FLAKES (priority 2, framework)

Objective: vukem CI is flaky on Windows and macOS runners and blocks merges. Observed 2026-10-29: `TestServeWithSSR` (macOS, 503 maintenance during startup), `TestSSRStartRestartsCrashedServer` (Windows), `fatal error: unknown caller pc` in the root package tests (Windows, run of PR #63), `internal/cli` timing out at 600 s (Windows, PR #65), `TestBrowser_APIDocsNoCSPViolations` (macOS, PR #61). For each: reproduce locally where possible (`-count=20 -race`), find the root cause (startup race, fixed ports, timeouts too tight, process cleanup, a real data race behind `unknown caller pc`), fix it; split or parallelise `internal/cli` tests so the package stays well under the timeout. Never skip or delete a test to get green; quarantine only with a linked issue and an owner-visible note. One PR per root cause. Do not run `gh pr merge`.
