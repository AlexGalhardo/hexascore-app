### Current state in one page

**Product.** Media database (games, movies, TV series, books) with six-category 0–100 user scores (`c1..c6`, `overall = round(sum/6)`), personal status, time-to-beat, lists, follows, feed, reports, and a paid read-only public REST API (plans free/pro/business, credit packs, Stripe + AbacatePay PIX). Version 0.0.25, release-please, Conventional Commits. Brand name still "pending" in docs although the domain `hexascore.app` is live.

**Stack.** Next.js 16.3.8 (App Router, `proxy.ts`), React 19.3, TypeScript 7.0.2, Drizzle 0.45.3 on postgres-js 3.4.9, PGlite 0.5.8 for tests and offline dev, Better Auth 1.7.7 (email+password, Google, TOTP, passkeys, admin/ban/impersonation), zod 4.6.5 everywhere (env, actions, API DTOs, OpenAPI via `z.toJSONSchema`), next-intl 4.14.9 (en default, pt-BR, es; 17 namespaces × 3 locales), Tailwind 4.3.3 + Base UI 1.8.0, TanStack Query 5, Upstash Redis + Ratelimit (API quota only), Resend + React Email, Vercel Analytics/Speed Insights, BotID, Flags SDK. Python 3.14 + uv for ingestion (httpx, psycopg 3 pipeline mode, pydantic, pillow). SDKs: `@hexascore/sdk` (hey-api, npm/JSR) and `hexascore` (openapi-python-client); neither published.

**Infra.** Vercel (iad1, Pro), Neon Postgres (branch per preview), Upstash via Marketplace, Vercel Blob for covers (written by Python only), 3 Vercel crons (flush API usage, billing reminders, purge accounts). Migrations run in `vercel-build`. Docker (`oven/bun:1.4.2`, Postgres 18.6, Redis 8.10.2 + serverless-redis-http) exists for local/self-host. Estimated Vercel+Neon cost: ~US$52/month at launch, ~US$160 growth, ~US$484–499 scale (`legacy/docs/vercel-costs-monthly.md`, prices of 2026-10-03).

**Data model.** 27 tables, 11 enums, 6 migrations. One `items` table for all four types (`type`, `slug`, `wikidata_qid` unique, `external_ids` jsonb, `meta` jsonb with type-specific fields, `popularity` = Wikidata sitelinks, denormalized `score`, `score_c1..c6`, `rating_count`); `item_translations` (title, synopsis with CC BY-SA licence + source URL, generated tsvector, trigram index); `external_scores` (Metacritic, Rotten Tomatoes; front-end only, never in the API); `affiliate_links`; `source_records` (ingestion staging keyed by Wikidata QID, payload hash). Social: `ratings` (PK user+item, CHECK 0–100), `item_status`, `time_to_beat`, `follows`, `lists`/`list_items` (one type per list), `reports`, `contact_messages`. Billing: `api_keys` (sha256), `subscriptions`, `credit_ledger`, `pix_charges`, `api_usage_daily`, `processed_events`, `stripe_customers`. **No community-edit / suggestion tables exist.** Score write path locks the item row and recomputes all aggregates from `ratings` in the same transaction; the 5-rating threshold is applied on read.

**Routes and API.** Pages under `app/[locale]/`: home, four section listings, item page, search, user profile + lists, feed, pricing, contact, policy, terms, auth (login, signup, recover, reset, verify, onboarding), profile (details, password, 2FA, passkeys, privacy, delete, API keys/usage/checkout), admin (contact, reports, items + merge, ingestion), docs (quickstart, auth, errors, pagination, rate limits, changelog, Scalar reference). 33 Server Actions in 11 files. Public API v1: 6 GET endpoints (`/v1/{type}`, `/v1/{type}/{id}`, `/v1/{type}/genres`, `/v1/search`, `/v1/lookup`, `/v1/me/usage`) behind `apiRoute()` (bearer `hx_live_` keys, plan-aware zod query validation, Upstash quota/throttle failing closed, RFC 9457 problems, `RateLimit-*` headers, 5xx refund). OpenAPI 3.1 per locale (`public/openapi*.json`), `openapi:check` CI gate. Host routing `api.hexascore.app/v1/*` done in `proxy.ts`.

**Ingestion.** Python connectors: Wikidata (SPARQL + entities, source of truth and QID key), Wikipedia extracts (en/pt/es), Open Library, Steam, GOG, TMDB and IGDB (added 2026-10-10). Pipeline `source_records → normalize.py → items/translations/external_scores`, `covers.py` (WebP 600 px + 96×144 thumb to Blob), `trailers.py` (YouTube oEmbed). Three GitHub Actions workflows (bootstrap, daily incremental `--since 36h`, weekly) exist but are **disabled** (GitHub Actions billing blocked); ingestion runs by hand from a developer machine against production Neon. Production holds 99,960 items; cover coverage: movies 99%, series 89%, games 92%, books 34%; ~3k items lack an English synopsis although a source overview exists; 10k synthetic users with ~2.1M ratings still live in production.

**Search.** Postgres only: pg_trgm `word_similarity` on titles + `websearch_to_tsquery('simple')` on the generated tsvector, ranked by `greatest()`. `unaccent` is installed but unused.

**Quality.** 34 unit test files (~183 cases, PGlite-backed), Playwright + axe (16 specs, ~86 tests), k6 (p95 < 300 ms target), Schemathesis, OWASP ZAP; 77 Python tests. All GitHub workflows disabled; `scripts/ci-local.sh` on pre-push is the gate (biome, typecheck, test, openapi:check, build, ruff/pytest).

### Pain points found

- Vercel/Next coupling: CSP nonce in `proxy.ts` makes every page dynamic (no ISR); `unstable_cache` because `cacheComponents` is off; sitemap rewrite hack; `bun --bun next build` crashes on Windows (Node fallback); BotID fails closed only on Vercel.
- Operations: no CI in the cloud, manual ingestion against production, no error tracking (Telegram env vars validated but unused), Vercel Firewall rules documented but not applied, QA secrets missing, orphan Blob files after cover replacement (20,360 in the 2026-10-10 run).
- Licensing: TMDB and IGDB data is served through the paid API without a commercial licence, contradicting `legacy/PLAN.md` §2. Open legal risk; must be settled in Phase 2.
- Docs drift: `legacy/AGENTS.md` still says "no application code yet"; `PLAN.md` says Python 3.13 while `pyproject.toml` requires ≥3.14; CHANGELOG compare links point to another repository; `external_score_source` enum and `affiliate_store` values never written; `BLOB_READ_WRITE_TOKEN` validated by the web app but unused.
- Cost drivers at scale: Vercel Web Analytics grows linearly with page views, Neon storage tier for 100k items, GitHub Actions minutes on a private repo.
