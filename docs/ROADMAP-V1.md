# Roadmap to a stable, public v1.0 (architect audit, 2026-11-02)

Executive summary: production has been live on Railway since the 2026-10-31 cutover with 98,841 items, legacy data migrated, and 300 of 343 roadmap boxes done. What separates today from a public 1.0 is not features but stability and operations: a locale cache bug (fixed), a nightly job that never finishes, erasure and retention gaps, an e2e suite that drifted, ingestion switched off, and a landing page that does not use the trending design. This roadmap sequences the audit backlog (`docs/BACKLOG.md`) into five milestones with exit criteria; `ROADMAP.md` stays the microtask ledger and gains phase P8 pointing here.

| Milestone | Target | Scope (backlog IDs) | Exit criteria |
| --- | --- | --- | --- |
| **V1-A Stabilise** | +2 weeks | B-001, B-002, B-010, B-011, B-012, B-014, B-024, B-025, B-026, B-027, B-033, B-034 | Production `/pt-br` and `/es` pages verified in the right language; nightly recompute completes (log line with the full item count, `queue:failed` empty for 7 days); Playwright `desktop-en` green locally and on the release candidate; erasure test green; pre-deploy runs `hexascore:predeploy`; staging reachable; worktrees cleaned; release `v0.39.0` with the full local gate |
| **V1-B Launch polish** | +4 weeks | B-020, B-021, B-022, B-023, B-040, B-041, B-042, B-043, B-044, B-046 | Lighthouse mobile: a11y 100, SEO 100, LCP ≤ 2.5 s on the five DemoCatalog URLs in the CI container; `og:image` on item pages; 404 pages; docs in English; release `v0.40.0` |
| **V1-C Worker live** | +6 weeks | B-013, B-029 (CW-01..CW-08, CW-14), B-031, B-047 | RFC-001 M0: worker service in staging 7 green days then production, 30-minute Telegram digest, refresh of all items with a cover inside 14 days, accuracy sample ≥ 97 %, spend ≤ US$12/month; release `v0.41.0` |
| **V1-D Trending and offers** | +9 weeks | B-028, B-030 | RFC-002 synthetic and historical tests green, home reads snapshots with turnover 1-3 items/day/type, pin/ban in admin; RFC-003 offers shown for ≥ 90 % of films/series with a TMDB id in BR and US, store links for ≥ 95 % of games with a store id, affiliate disclosure live only where a tag exists; release `v0.42.0` |
| **v1.0.0 public** | +10 weeks | B-032, B-045, final docs sync, 30-day green-jobs clock from V1-C | All P0/P1 closed; 30 consecutive days of green nightly jobs and worker digests; error budget: ≤ 0.1 % 5xx on public pages (Railway HTTP metrics), p95 TTFB ≤ 800 ms on item pages; backups restored in the monthly drill; owner gates in `ROADMAP.md` either closed or explicitly deferred; `ADR 0013` cutover retention window closed and legacy routes removed; tag `v1.0.0` and GitHub release |

After 1.0: RFC-001 M1-M3 (250 k → 1 M items, each a minor release with the sampling report), social layer flag (Q-A5), mobile store release (P5.C), multi-replica readiness when ADR 0024's trigger fires.

Principles that hold across milestones: every change behind a flag or kill switch where behaviour changes; no new infrastructure without an ADR; spend alert at US$18 and hard limit US$20 (D-27); the release gate (`scripts/ci/local.sh`) before every push to `main` while Q-A21 is in force, and PR-first again when the owner re-enables the ruleset.
