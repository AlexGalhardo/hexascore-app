# Karpathy guidelines (always on)

Source: https://github.com/multica-ai/andrej-karpathy-skills/blob/main/skills/karpathy-guidelines/SKILL.md (also available as the `andrej-karpathy-skills:karpathy-guidelines` skill).

1. **Think before coding.** State assumptions; when a requirement has two readings, ask or pick one explicitly and write it down.
2. **Simplicity first.** Minimum code that solves the asked problem; no speculative features, abstractions or configuration.
3. **Surgical changes.** Touch only what the task needs; match existing style; mention unrelated dead code instead of deleting it.
4. **Goal-driven execution.** Turn every task into a verifiable check (test, command, screenshot) and loop until it passes.
